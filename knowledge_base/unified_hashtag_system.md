# Унифицированная система хештегов (Car Hauling Unified Hashtag Taxonomy)

Данная спецификация регламентирует формат разметки сообщений в Telegram-канале «Грузовики на базу», админ-кабинете и автоматических пайплайнах генерации новостей и дорожных оповещений.

Цель системы — мгновенная фильтрация информации оунер-оператором прямо из кабины трака по ключевым критериям: **Срочность**, **Маршрут**, **Штат**, **Сетап**.

---

## 1. Формула составления хештегов в посте

Каждое сообщение, публикуемое ботом, диспетчером или n8n-воркфлоу, **ОБЯЗАНО** содержать в конце минимум 3 хештега по формуле:

```text
#[Тип_сообщения] #[Трасса_или_Регион] #[Штат] #[Сетап_или_Тематика (опционально)]
```

*Примеры:*
- Экстренный дорожный алерт: `#Алерт #I80 #WY #Стингер #Погода`
- Рейд DOT на весах: `#Весы #I70 #OH #DOT_Рейд`
- Анализ аукционного рынка: `#Новости #Рынок #Манхейм #Ставки`
- Инструкция по простою: `#SOS_Совет #Детеншен #Брокеры`

## 2. Категории хештегов

### Уровень 1: Тип публикации (Category & Severity)
| Хештег | Назначение | Частота |
| :--- | :--- | :--- |
| `#Алерт` | Критические дорожные инциденты, завалы, перекрытия перевалов, штормовой ветер | Мгновенно по факту |
| `#Весы` | Открытые weigh stations, мобильные весы DOT, облавы на овервейт/ELOG | По факту |
| `#Новости` | Важные события автовоза: законы FMCSA, банкротства брокеров, правила стоянок | 1-2 раза в день |
| `#Ставки` | Аналитика RPM (Rate Per Mile), спрос по коридорам, аукционные коэффициенты | 2-3 раза в неделю |
| `#Погода` | Метеоусловия: блэк-айс, цепи (Chain Law), снегопады, торнадо в Midwest | В сезон / оперативно |
| `#SOS_Совет` | Памятка водителям: формулы расчетов, споры с брокерами, юридические шаблоны | 1 раз в 1-2 дня |
| `#ЧерныйСписок` | Брокеры-мошенники, дабл-брокеры, аннулированные бонды BMC-84 | По прецеденту |

| Хештег | Описание артерии |
| :--- | :--- |

| `#I70` | Центральный коридор через горы (MD -> PA -> OH -> IN -> IL -> MO -> KS -> CO -> UT) |
| `#I10` | Южный коридор побережье-побережье (FL -> AL -> MS -> LA -> TX -> NM -> AZ -> CA) |
| `#I40` | Южно-центральный коридор (NC -> TN -> AR -> OK -> TX -> NM -> AZ -> CA) |
| `#I95` | Восточное побережье (FL -> GA -> SC -> NC -> VA -> DC -> MD -> PA -> NJ -> NY -> MA) |
| `#I75` | Центральный Север-Юг (FL -> GA -> TN -> KY -> OH -> MI) |
| `#I15` | Западный межгорный коридор (CA -> NV -> UT -> ID -> MT) |
| `#I5` | Западное побережье (CA -> OR -> WA) |
| `#I81` | Обход I-95 по Аппалачам (TN -> VA -> WV -> MD -> PA -> NY) |
| `#I65` | Средний Запад к Заливу (AL -> TN -> KY -> IN) |
| `#I35` | Техасский центральный коридор (TX -> OK -> KS -> IA -> MN) |

### Уровень 3: Регионы и ключевые штаты (Regions & States)
Используются официальные двухбуквенные почтовые аббревиатуры США:

- **Штаты с высоким автовозным трафиком:**  
  `#TX` (Техас), `#CA` (Калифорния), `#FL` (Флорида), `#PA` (Пенсильвания), `#OH` (Огайо), `#IL` (Иллинойс), `#GA` (Джорджия), `#NJ` (Нью-Джерси), `#NC` (Северная Каролина), `#MI` (Мичиган), `#IN` (Индиана), `#TN` (Теннесси).
- **Сложные горные / зимние штаты (Chain Law, Wind):**  
  `#WY` (Вайоминг), `#CO` (Колорадо), `#UT` (Юта), `#NV` (Невада), `#OR` (Орегон), `#WA` (Вашингтон), `#MT` (Монтана), `#NE` (Небраска).
- **Регионы (для сводных обзоров):**  
  `#Midwest`, `#WestCoast`, `#EastCoast`, `#South`, `#Rockies`, `#TriState`, `#GreatLakes`.

## 3. Требования к LLM-генератору по расстановке хештегов
При генерации любого новостного или оперативного поста модель Gemini обязана:
1. Выбрать ровно **один** главный тип (`#Новости` или `#Алерт` или `#Весы`).
2. Определить, упоминается ли конкретная магистраль (например, если речь о Вайоминге — автоматически добавлять `#I80` и `#WY`).
3. Добавить целевой сетап, если новость критична для конкретной техники (например, высокий ветер — `#Стингер #Виджик`).
4. Помещать блок хештегов в самый конец сообщения с отступом в одну пустую строку.
